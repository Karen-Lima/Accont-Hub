📌 Como sincronizar com o Pipefy
O arquivo HTML está sendo aberto diretamente (file://), o que bloqueia chamadas de API por CORS.
Para sincronizar com o Pipefy, use uma das opções abaixo:
OPÇÃO 1 — VS Code Live Server
Instale a extensão Live Server no VS Code → clique direito no arquivo → Open with Live Server
OPÇÃO 2 — Python servidor local
Na pasta do arquivo: python -m http.server 8080 → abra localhost:8080
OPÇÃO 3 — Netlify Drop
Arraste o arquivo para app.netlify.com/drop e acesse pela URL gerada
